## Code Highlighting

Syntax highlighting powered by Shiki with dual themes (light & dark):

```typescript
interface BlogPost {
  title: string;
  pubDate: Date;
  tags: string[];
  draft: boolean;
}

function getRecentPosts(posts: BlogPost[], n = 5): BlogPost[] {
  return posts
    .filter((p) => !p.draft)
    .sort((a, b) => b.pubDate.valueOf() - a.pubDate.valueOf())
    .slice(0, n);
}
```
